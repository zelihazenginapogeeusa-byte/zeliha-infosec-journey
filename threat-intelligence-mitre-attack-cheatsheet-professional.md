# Pentest & SOC Cheat Sheets

A personal reference collection built while preparing for **eJPT** (offensive) and **BTL1** (defensive) certifications. Organized by team so it's easy to find the right sheet mid-lab or mid-exam.

## 📁 Structure

```
.
├── red-team/     — eJPT-focused: enumeration, exploitation, web attacks, social engineering
├── blue-team/    — BTL1-focused: SIEM, forensics, malware analysis, incident response
└── assessment-methodology-report-writing-cheatsheet-professional.md   — shared by both
```

See [`red-team/README.md`](red-team/README.md) and [`blue-team/README.md`](blue-team/README.md) for the full file index in each folder.

## Note

These are reference sheets for recalling syntax/workflow quickly — not a substitute for hands-on lab practice (TryHackMe/AttackDefense for eJPT, the BTL1 lab environment for BTL1).

*All offensive techniques should only be used within written authorization (scope/RoE).*
