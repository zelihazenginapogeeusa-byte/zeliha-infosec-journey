Step by step

1 Deleted Files

On the left-hand side, check the Results panel:

Results → Deleted Files

This lists everything Autopsy has flagged as deleted. Depending on the version, you may instead see it under:

Data Artifacts → Deleted Files

2 Unallocated Space

On the left-hand side:

Data Sources → [disk/image] → File System

Explore the disk structure here. Specifically check Unallocated Space or a $Unalloc-style area — this is where file fragments can sit that never appear in the normal folder structure.

Note: some Autopsy versions don't present unallocated space as a browsable folder. When that's the case, the Deleted Files and File Carving results are more useful.

3 Hidden Files / File Attributes

There's an important distinction here: finding a "hidden file" in Autopsy isn't as simple as looking for the "Hidden" checkbox in Windows Explorer.

Click a file and check the File Metadata or Details / File Attributes panel on the right.

On Windows images, look specifically for these attributes:

Hidden
System
Read-only
Archive

On Linux images, pay attention to filenames starting with .:

.secret
.hidden.txt

4 File Name — suspicious names

On the left-hand side, navigate:

File System → [partition] → [directory]

Once the file listing is open, sort by the Name column. For example, check files like:

report.txt
notes.txt
.secret.txt
.hidden.txt
backup.txt

Pay particular attention to names starting with ., $, ~, or anything otherwise unusual.

5 Extension Mismatch

This one matters a lot for forensic investigations. On the left-hand side, check:

Results → Extension Mismatch

if it's available. For example, you might see a result like:

filename: report.txt
actual type: JPEG image

That means the file is named .txt but is actually a JPEG. This kind of mismatch often surfaces files whose extension was deliberately changed to hide them.

6 Keyword Search

One of Autopsy's most useful features. Use the Keyword Search panel at the top. For example, search for:

password

or:

secret

or:

flag

The results show every file containing that term. You can also filter results down to a specific file type if you want to narrow the search.

7 File Type / MIME Type

On the left-hand side, check:

Results → File Types

or, in some versions, the File Types category directly. Autopsy can classify files by actual content type:

Images
Documents
Archives
Executables
Text
Videos

This matters because a file's extension and its real content can disagree — for example, secret.txt might actually be a JPEG.
